# FORJA Training Club · Web para gimnasio

Web de muestra para un gimnasio ficticio en Madrid, diseñada y desarrollada como proyecto de portfolio.

🔗 **Ver la web:** [forja-training-club.netlify.app](https://forja-training-club.netlify.app)

## Tecnologías

- HTML, CSS y JavaScript sin frameworks
- GSAP 3 + ScrollTrigger para las animaciones de scroll
- Diseño mobile-first

## Animaciones de scroll

- Barra de progreso de lectura
- Hero que se recorta hasta convertirse en tarjeta
- Manifiesto que se ilumina palabra a palabra
- Contadores animados
- Clases con desplazamiento horizontal (sección fijada en escritorio)
- Texto gigante que se mueve con el scroll y parallax en las fotos
- Respeta `prefers-reduced-motion`
